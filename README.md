# 247 Managed Network Solutions Website

Production-ready static website for 247 Managed Network Solutions, an outsourced .NET, Blazor, and SwiftUI software development company.

- `index.html` - Website content, SEO metadata, Open Graph tags, and JSON-LD schema.
- `assets/styles.css` - Responsive visual design.
- `assets/app.js` - Mobile navigation, FAQ toggles, and static email form behavior.
- `assets/logo.png` - Logo copied from the original project folder.

## Deployment

Upload the full folder contents to any static web host. The contact form is intentionally backend-free: it opens a prepared email to `sales@247managed.com`.

If the production domain is not `https://247managed.com/`, update the canonical URL, Open Graph URL, JSON-LD URL fields, `robots.txt`, `sitemap.xml`, and every root-relative internal URL that should point to the final domain.
