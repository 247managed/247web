**Purpose**: Atmospheric background video for the main hero section

**Aspect Ratio**: 16:9 (1920x1080 minimum)  
**Style**: Cinematic, professional, premium tech aesthetic

### Prompt:

```
A cinematic, slowly rotating view through a premium software development studio at golden hour. 
Camera: Smooth dolly movement from right to left, subtle push-in towards architectural diagrams and glowing screens. 
Scene: Modern minimalist office with floor-to-ceiling windows, warm natural light mixing with cool blue monitor glow. 
Foreground: Elegant desk with multiple monitors displaying abstract code patterns, UI wireframes, and architectural diagrams - nothing readable, just aesthetic patterns. 
Mid-ground: Large glass whiteboards with navy blue and orange geometric diagrams, flowcharts, and system architecture sketches.

Color Palette: Navy blue (#2A4A64), warm orange/gold (#F0A019), white, charcoal gray, warm sunlight. 
Atmosphere: Professional, calm, focused energy. Subtle lens flare from the setting sun. 
Details: No people visible, no readable text or logos. Clean, organized workspace that feels alive but contemplative. 
Lighting: Warm key light from window (right side), cool blue fill from monitors, soft rim lighting on edges. 
Camera Movement: Ultra-smooth 3-axis gimbal motion, 2-second ease in/out, constant subtle movement throughout. 
Quality: Cinematic depth of field (f/2.8), color graded for premium feel, slight film grain for texture.
```

**Technical Notes**:
- Export as MP4 (H.264), 30fps minimum
- Ensure seamless loop (first and last frames should match)
- Compress for web (<5MB if possible) while maintaining quality
- Fallback: Use high-res still image from the sequence

## Export Specifications for All Videos

**File Formats**:
- Primary: MP4 (H.264 codec)
- Fallback: WebM (VP9 codec) for modern browsers
- Poster Images: JPG at key frames for fallback

**Quality Settings**:
- Resolution: 1920x1080 minimum (4K preferred for downsampling)
- Frame Rate: 30fps minimum, 60fps preferred
- Bitrate: 8-12 Mbps for high quality, optimize below 5MB for hero loop
- Audio: 48kHz, AAC codec (if applicable)

**Web Optimization**:
- Compress without visible quality loss
- Use modern codecs (H.265 if browser support is adequate)
- Provide multiple resolutions (1080p, 720p, 480p for adaptive streaming)
- Ensure fast start (moov atom at beginning of file)

## Integration Notes

**Hero Video**: 
- Implement with `<video>` tag, autoplay, loop, muted, playsinline
- Fallback to static image if video fails to load
- Lazy load if below the fold

**Social Media Clips**:
- Export square (1:1) for feed posts
- Export vertical (9:16) for Stories/Reels/Shorts
- Add burned-in captions for accessibility
- Include 1-2 second padding at start/end for platform compatibility

**Tech Highlight Clips**:
- Keep under 15 seconds for maximum social media engagement
- Reserve visual space for text overlays
- Export with transparent title space if possible
- Provide versions with and without text
